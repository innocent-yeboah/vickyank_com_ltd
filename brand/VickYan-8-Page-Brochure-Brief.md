## Brand system (apply on every page)

| Element | Spec |
|--------|------|
| Primary type | Montserrat Bold / ExtraBold — headlines |
| Secondary type | Montserrat Medium — section labels |
| Body | Inter / Open Sans Regular — 10–11 pt |
| Eyebrow labels | All caps, 9–10 pt, tracking +200, Gold on navy / Navy on white |
| Rules | 1–2 pt gold hairline under section titles |
| Photography | Desaturated industrial / luxury; gold accent overlays only at edges |
| Footer strip | Thin navy or gold bar with page number (right) + “VickYank Limited” (left) |

## Canva setup (5 minutes)

1. Open [Canva](https://www.canva.com) → **Create a design** → **Custom size** → **210 × 297 mm** (A4).
2. Add **7 more pages** (total **8**).
3. **Brand Kit** (Pro) or manual:
   - Colors: `#D4AF37`, `#1A1A2E`, `#FFFFFF`, `#2D2D2D`
   - Upload logo: `vickyank-logo.png`
   - Fonts: Montserrat + Open Sans (or Inter)
4. Master footer: duplicate on pages 2–8.
5. Export: **PDF Print** → flatten text optional → CMYK if print house requires; otherwise RGB PDF is fine for digital share.
